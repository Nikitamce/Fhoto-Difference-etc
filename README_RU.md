# PhotoCheck — Инструмент визуального сравнения и выравнивания фото 🔍

[**Read in English 🇬🇧**](README.md) | **Русский 🇷🇺**

**PhotoCheck** — это мощное оффлайн веб-приложение для точного визуального сравнения фотографий, поиска разницы в пикселях и геометрического совмещения кадров. Разработано для разработчиков игр, QA-инженеров, дизайнеров, архивариусов и фотографов.

Программа позволяет загружать два изображения, выравнивать их с помощью ИИ или многоточечных геометрических трансформаций, а также находить даже мельчайшие визуальные отличия с помощью интерактивной шторки, наложения прозрачности, быстрого мигания и вычитания пикселей (Diff).

## ✨ Основные возможности

- 🚀 **100% Оффлайн и Портативность в одном файле**: Запускается прямо в любом браузере без установки (`PhotoCheck_Portable.html`). Включает в себя встроенный движок OpenCV.js и не требует подключения к интернету.
- 🔍 **4 Режима сравнения**:
  - **Шторка (Slider)**: Перетаскивание вертикальной или горизонтальной линии разделителя между кадрами A и B.
  - **Наложение (Fade)**: Регулировка прозрачности фото A (0%–100%), режимы ручного мигания вспышкой и автоматического интервального мигания.
  - **Рядом (Split)**: Параллельный просмотр двух изображений с синхронным перемещением и масштабированием.
  - **Подсветка разницы (Diff)**: Математическое вычитание пикселей (`|Кадр A - Кадр B|`) с усилением контраста для яркой неоновой подсветки любых измененных пикселей.
- 🤖 **Инструменты автовыравнивания и геометрической подгонки**:
  - **Автовыравнивание AI (OpenCV)**: Поиск ключевых точек (ORB) + сопоставление RANSAC для интеллектуального совмещения ракурсов.
  - **Найти контуры (Авто)**: Многоуровневый алгоритм ZNCC по гибридным картам градиентов Sobel и контраста. Автоматически отфильтровывает темные фоновые полосы, точечно фиксируясь на тексте интерфейса, объектах и деталях.
  - **По 1 точке**: Центрирование и смещение кадра B по 1 базовой реперной точке.
  - **По 2 точкам**: Совмещение положения и масштаба по 2 точкам.
  - **По 3 точкам (Поворот)**: Аффинное вращение, масштаб и смещение по 3 точкам.
  - **Деформация перспективы (4 точки)**: Перспективное гомографическое выравнивание (Homography Transform) для снимков, сделанных под углом, или накренившихся сканов документов.
- 🔎 **Ультра-зумирование до 1000%**: Синхронное панорамирование и зумирование колесиком мыши относительно точки курсора.
- 🌐 **Полная двухъязычная локализация (i18n)**: Мгновенное переключение между Русским 🇷🇺 и Английским 🇬🇧 языками.
- 📊 **Панель инспекции и метаданных**: Просмотр разрешения, формата, размера файла, глубины цвета, альфа-канала и DPI.

## 🚀 Быстрый старт

### Способ 1: Запуск автономного файла (Без установки)
Просто скачайте [**`PhotoCheck_Portable.html`**](PhotoCheck_Portable.html) из данного репозитория и откройте его в любом браузере (Chrome, Firefox, Edge, Safari, Opera).

### Способ 2: Запуск для разработки
```bash
# 1. Клонировать репозиторий
git clone https://github.com/Nikitamce/Fhoto-Difference-etc.git
cd Fhoto-Difference-etc

# 2. Установить зависимости
npm install

# 3. Запустить локальный сервер разработки
npm run dev
```

### Сборка одного HTML файла
Чтобы собрать приложение в единый портативный HTML-файл:
```bash
npm run build
```
Готовый файл создаётся в `dist/index.html` и автоматически копируется в `PhotoCheck_Portable.html`. Проверки геометрии запускаются командой `npm test`.

## 🌍 Инструкция по локализации и переводу на новые языки

Мы приветствуем вклад сообщества в перевод **PhotoCheck** на новые языки (немецкий, французский, испанский, китайский, японский и др.)!

### Как добавить новый язык

1. **Сделайте Fork и клонируйте репозиторий**:
   ```bash
   git clone https://github.com/Nikitamce/Fhoto-Difference-etc.git
   cd Fhoto-Difference-etc
   ```

2. **Добавьте словарь перевода в файл [`src/i18n.js`](src/i18n.js)**:
   Откройте `src/i18n.js` и добавьте код вашего языка (например, `de` для немецкого) внутрь объекта `translations`:
   ```javascript
   const translations = {
     ru: { ... },
     en: { ... },
     de: {
       appTitle: "PhotoCheck — Visueller Fotovergleich",
       modeSlider: "Vorhang (Slider)",
       modeFade: "Überlagerung (Fade)",
       // Переведите остальные ключи
     }
   };
   ```

3. **Добавьте пункт выбора в меню языков в [`index.html`](index.html)**:
   В файле `index.html` найдите `#lang-dropdown-menu` и добавьте новую кнопку:
   ```html
   <button class="dropdown-item lang-option" data-lang="de">🇩🇪 Deutsch (DE)</button>
   ```

4. **Обновите отображение флага в [`src/i18n.js`](src/i18n.js)**:
   В методе `I18nManager.updateUI()` укажите ваш флаг и код:
   ```javascript
   if (this.currentLang === "de") {
     currentFlagEl.textContent = "🇩🇪";
     currentCodeEl.textContent = "DE";
   }
   ```

5. **Проверьте работу локально**:
   ```bash
   npm run dev
   ```

6. **Соберите сборку и создайте Pull Request (PR)**:
   ```bash
   npm run build
   git checkout -b feature/add-german-translation
   git add src/i18n.js index.html PhotoCheck_Portable.html
   git commit -m "feat(i18n): Add German translation"
   git push origin feature/add-german-translation
   ```
   Откройте **Pull Request** на GitHub в репозиторий `Nikitamce/Fhoto-Difference-etc`. Мы проверим и слим его в ветку `main`!
