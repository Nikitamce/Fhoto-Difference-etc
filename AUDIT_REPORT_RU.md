Дата ревизии: 15 ноября 2026 г.

## Объём проверки

Проверены `index.html`, `styles.css`, `src/app.js`, `src/studio.js`, `src/viewer.js`, `src/modes.js`, `src/transform_math.js`, `src/auto_align.js`, `src/opencv_align.js`, `src/i18n.js`, `src/opencv.js`, `package.json`, `package-lock.json` и конфигурация Vite.

## Найденные причины неработающих кнопок

### 1. Открытие `index.html` двойным щелчком

PhotoCheck использует JavaScript ES-модули. Большинство браузеров блокирует их загрузку с адреса `file://`. В результате HTML и CSS показываются, но `app.js` и `studio.js` не запускаются, поэтому кнопки не получают обработчики.

**Исправление:** добавлено понятное предупреждение поверх интерфейса при запуске через `file://`, а также `START-WINDOWS.bat`, `START-HERE-RU.txt` и встроенный `server.mjs`. Локальный сервер запускается на `127.0.0.1`, не требует npm-пакетов и автоматически выбирает следующий свободный порт, если порт 4173 занят.

### 2. Экспорт не видел загруженные изображения

Главное приложение создаёт элементы `<img>` динамически во время своей инициализации. `studio.js` мог получить ссылки на эти элементы до их создания и сохранить `null`. Поэтому экспорт отдельных файлов и текущего сравнения сообщал, что изображение не загружено, хотя оно уже отображалось на экране.

**Исправление:** ссылки на основные и split-изображения теперь обновляются при изменениях DOM через уже используемый `MutationObserver`. Проверены реальные загрузки PNG через браузерный download event.

### 3. OpenCV загружался как ES-модуль вместо классического скрипта

Файл `opencv.js` — классическая сборка Emscripten/UMD. Импорт через `?raw` работал только при специальной обработке Vite и ломался при обычной статической раздаче: появлялась ошибка `ReferenceError: Module is not defined`.

**Исправление:** OpenCV загружается отдельным классическим `<script>` с локальным URL, а глобальная конфигурация `Module` создаётся до запуска. Это работает и через локальный сервер, и в Vite-режиме.

## Другие исправления, сделанные в аудите

### Геометрия и выравнивание

- Устранена повторная компенсация смещения B при независимом увеличении A.
- Ручная подгонка B в режиме «Рядом» использует координаты правой панели, а не всей рабочей области.
- «Совместить размер» учитывает ручной масштаб A и геометрически усредняет отношение ширины и высоты.
- Изменение размера A сохраняет положение B; изменение размера B сохраняет центр B.
- При замене изображений, перестановке A/B, сбросе или запуске ручного инструмента устаревшие асинхронные результаты авто-выравнивания отбрасываются.
- Ограничен размер промежуточных карт автоматического поиска контуров; для экстремальных пропорций алгоритм предлагает более подходящий режим вместо чрезмерно тяжёлого глобального поиска.

### Загрузка и интерфейс

- Состояние пары изображений синхронизируется с основным приложением.
- Объектные URL освобождаются при замене, удалении и закрытии страницы.
- Инструменты, которым обязательна пара A/B, отключены до загрузки обоих изображений.
- Ползунки ручного масштаба соответствуют диапазону модели 0,1×–10×.
- Сброс возвращает основные параметры сравнения и выравнивания к предсказуемому состоянию.
- Добавлены локализованные сообщения для ключевых операций.
- Удалена загрузка Google Fonts: для интерфейса используются системные шрифты.
- В пустом состоянии не показываются фиктивные метаданные и несуществующие миниатюры.

### Экспорт

- Через меню доступны текущая композиция, оба оригинала рядом и каждый оригинал отдельно.
- Для перспективного преобразования используется сеточное приближение гомографии, поскольку Canvas 2D не имеет нативной projective transform.
- Учитываются ограничения размеров canvas и бюджета пикселей.
- Меню закрывается по Escape и возвращает фокус на кнопку, открывшую его.

## Что не удалось подтвердить

- Полную production-сборку Vite (`npm run build`) не удалось выполнить в этой среде: установленные каталоги npm-зависимостей неполные, а `npm ci` завершился по тайм-ауту. Поэтому сборка single-file Portable HTML в этот архив не включена.
- Загрузка OpenCV и создание API проверены в браузере. Успех самого автоматического совмещения зависит от наличия достаточных совпадающих деталей в конкретной паре изображений; на демонстрационной паре алгоритм корректно отказывается принимать ненадёжные совпадения.

## Как запустить исправленную версию

**Windows:** распаковать архив полностью и запустить `START-WINDOWS.bat`. Требуется Node.js 18 или новее. `npm ci` для этого способа не нужен.

**Любая ОС:** выполнить `node server.mjs` из папки проекта и открыть адрес, который появится в терминале (обычно `http://127.0.0.1:4173/`).

Не открывайте `index.html` двойным щелчком — используйте локальный сервер.

Для разработки через Vite:

```bash
npm ci
npm run dev
```
